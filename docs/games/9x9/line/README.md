# Splitting the board

Shown on the "Splitting the board" slide, after the Symmetry section slide. A made-up game showing a typical beginner pattern: each move is played next to the opponent's last one, so the two players build walls along a single border across the middle.

- Black's wall: A5–E5, then E4 and F4–J4. White's wall sits directly above it: A6–F6 and F5–J5.
- Both players pass after 20 moves. Every point is either a wall stone or one side's territory: Black 31 points below, White 30 above, no neutral points.
- With 6.5 komi under Japanese rules, White wins by 5.5.

It is an ordinary scored game in `index.json` (`"scored": true`, no dead stones), so the score card shows the split at the end.
