# Professional 9x9 games

Shown on the "Pro games" slide. All come from the 9x9 collection in Andries Brouwer's [Database of Go Games](https://homepages.cwi.nl/~aeb/go/games/) at CWI (`9x9.tgz`, downloaded 2026-11-07). The SGF files are copied unchanged. Sources inside the collection: the Mini-Go TV series (Yomiuri TV), NHK broadcasts, the 2008 Igo Festival, the Ricoh Pro Pair Go Cup, celebration games, Go Seigen's 1968 games, and pro-versus-computer matches.

## Weird and interesting games (listed first in the menu)

- **pro-minigo-981031.sgf**: Mirror go: White copies Black's moves through the centre point for 13 moves in a row.
- **pro-minigo-900414.sgf**: Mirror go again: 11 mirrored moves before the game breaks apart. Ends by resignation.
- **pro-go-seigen-1968-08-00.sgf**: Go Seigen plays 9x9 with no komi. A long game (80 moves) with captures on both sides.
- **pro-go-seigen-1968-09-00a.sgf**: Go Seigen as Black, no komi. The record stops with borders still open, so the score is reconstructed.
- **pro-computer-ji1.sgf**: The program Fuego, as White, beats Zhou Junxun 9p in an even 9x9 game (2009).
- **pro-computer-tw.sgf**: The program MoGoTW, as Black, beats Zhou Junxun 9p (2009). Ends by resignation.
- **pro-computer-oz2.sgf**: The program Zen, as White, beats Ohashi Hirofumi 5p by 2 points with 7 komi (2012).
- **pro-computer-do2.sgf**: Cho Riyu 8p beats the program Zen by half a point at the first Go Denosen (2014).
- **pro-misc-igofestival2008-6.sgf**: An exchange game: 28 stones captured between them over 89 moves, decided by 1.5 points.
- **pro-minigo-990612.sgf**: Trades all over the board: 8 captures each, and White wins by 11.5.
- **pro-minigo-881224.sgf**: Only 29 moves: most of the board is still open. Counting it means judging every border.
- **pro-misc-500-dan-celebration.sgf**: Eight Kitani-school pros together as Black against Cho Chikun. Cho wins.
- **pro-minigo-010701.sgf**: White loses on time, after Black captures a 7-stone group.
- **pro-misc-iyama-6crown-3.sgf**: Iyama Yuta vs Yuki Satoshi at Iyama's six-crown celebration (2013).

## How the scores are worked out

Pro game records don't say which stones were dead at the end, and many stop before every border is closed. `tools/score-games.mjs` fills in `dead`, `scoreMethod` and `scoreNote` in `index.json`:

1. **Playouts:** from the final position it plays 3,000 random games to the end (never filling a player's own eye) and records who ends up owning each point. A group whose stones mostly end up owned by the opponent is dead.
2. **Check:** it counts the position with those dead stones and compares the result with the record's `RE`.
3. **Fit to the result:** if they differ, it tries treating groups the playouts were unsure about (15–85% alive) the other way, fewest changes first. Groups the playouts were sure about are never changed.
4. **Neutral points:** if that still doesn't match, it tries counting one or two territory points as neutral, which is how a missing protective move (teire) shows up in a Japanese count.
5. Anything adjusted is explained on the score card, with board coordinates.

The "Scoring" column: *as played* = no dead stones needed; *playouts* = dead stones from step 1, count matches; *playouts, fitted* = step 3 used; *playouts + neutral point* = step 4 used; *no count* = resignation or time.

To rescore after adding games: `node tools/score-games.mjs docs/games/9x9/pro [file.sgf ...]` (about 3 seconds per game).
