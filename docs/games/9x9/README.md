# 9x9 demo games

Professional 9x9 games from Andries Brouwer's [Database of Go Games](https://homepages.cwi.nl/~aeb/go/games/) at CWI (its 9x9 collection, `9x9.tgz`), downloaded 2026-11-07. The SGF files are copied unchanged. Most are from the Mini-Go TV series (Yomiuri TV); the rest are from NHK New Year broadcasts, the 2008 Igo Festival, and the 2004 Pro Pair Go championship.

All of them end in a count, and for each one the board's own scoring gives exactly the recorded result without marking any dead stones, so the score overlay is correct for every game. All use Japanese counting.
